# Product screenshot preparation

The September 28 gallery contains 12 newly supplied app views plus the existing live-voice view, all edited with the built-in image editing tool. Originals stay outside the published asset directory.

Editing brief: crop away Windows title bars, taskbars and empty side gutters; retain the MAX header and controls; bake strong privacy blur into profiles, contact identities, phone numbers, chat text, memory entries, timestamps, key suffixes and configuration identifiers. The live-voice view is cropped to its dialog and conversations are blurred.

These are edited product previews, not unmodified pixel-exact captures. Image editing may alter small visual details. The device-fleet view remains explicitly marked as coming soon, and the automation view retains its executor limitation.

Published images and their full-size links use only the cleaned assets in `public/product-screenshots`. There are no CSS-only privacy masks and no original-image links. Review every edited image at full size before publishing.
